# Avatares do Quiz

Esta pasta deve conter as seguintes imagens de avatares:

1. **masculino-preto.png** - Avatar masculino com cabelo preto
2. **feminino-preto.png** - Avatar feminino com cabelo preto
3. **masculino-marrom.png** - Avatar masculino com cabelo marrom
4. **feminino-marrom.png** - Avatar feminino com cabelo marrom
5. **masculino-loiro.png** - Avatar masculino com cabelo loiro
6. **feminino-loiro.png** - Avatar feminino com cabelo loiro

## Especificações

- Formato: PNG
- Tamanho recomendado: 200x200px ou proporcional
- Fundo: Transparente ou sólido (será exibido em cards arredondados)

Os avatares são exibidos em um grid de 3 colunas na página de configuração do perfil da criança.
