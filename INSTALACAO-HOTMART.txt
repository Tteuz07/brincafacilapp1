🚀 COMO COMEÇAR:

1️⃣ OBTER CREDENCIAIS DA HOTMART
   
   Acesse: https://app-vlc.hotmart.com/tools/api
   
   Obtenha:
   • Client ID
   • Client Secret
   
   Gere o Basic Auth (Base64):
   $ echo -n "CLIENT_ID:CLIENT_SECRET" | base64

2️⃣ CONFIGURAR VARIÁVEIS DE AMBIENTE

   Crie o arquivo .env na raiz do projeto:
   
   VITE_HOTMART_CLIENT_ID=seu_client_id
   VITE_HOTMART_CLIENT_SECRET=seu_client_secret
   VITE_HOTMART_BASIC_AUTH=seu_basic_auth_base64
   VITE_HOTMART_PRODUCT_ID=seu_product_id

3️⃣ TESTAR A INTEGRAÇÃO

   $ node test-hotmart-integration.js
   
   ✅ Todos os testes devem passar!

4️⃣ EXECUTAR O PROJETO

   $ npm run dev
   
   Acesse: http://localhost:5173/login
   
   Teste com um email que tenha compra na Hotmart

  ✅ COMPLETE  → Compra completa

  ❌ PENDING   → Aguardando pagamento
  ❌ CANCELLED → Cancelada
  ❌ REFUNDED  → Reembolsada

🔧 SOLUÇÃO DE PROBLEMAS:

  "Hotmart Não Configurada"
  → Configure as credenciais no arquivo .env

  "Erro ao obter token"
  → Verifique Client ID, Secret e Basic Auth

  "Nenhuma compra encontrada"
  → Confirme se o email e Product ID estão corretos
  → Aguarde alguns minutos após a compra para sincronização
